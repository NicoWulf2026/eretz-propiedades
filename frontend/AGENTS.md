# Inmocapital Frontend Rules

## Project Overview
Inmocapital is a premium real estate platform focused on:
- property search
- interactive maps
- analytics
- AI-powered assistance
- real estate market intelligence

The UX must feel:
- premium
- modern
- fast
- trustworthy
- simple to use
- mobile friendly

## Frontend Stack
- Next.js
- React
- TypeScript
- Tailwind CSS

## Design Rules
- Use reusable components
- Mobile-first responsive design
- Clean spacing
- Premium visual hierarchy
- Avoid cluttered interfaces
- Dark blue and white primary palette
- Smooth transitions and hover states
- Minimal but premium design

## UI Priorities
1. Map experience
2. Property listing experience
3. Filters
4. Search UX
5. AI assistant
6. Analytics

## Coding Rules
- Keep components modular
- Avoid giant files
- Use TypeScript strictly
- Avoid unnecessary dependencies
- Prioritize performance
- Avoid breaking existing UI
- Use clear naming conventions

## Components Structure
- components/layout
- components/map
- components/property
- components/search
- components/filters
- components/chat
- components/ui

## Product Principles
- Search neutrality is critical
- Users must trust the platform
- Data quality is extremely important
- UX simplicity is mandatory
- Performance matters more than flashy animations

## Important
Never redesign the whole app unnecessarily.
Always preserve and improve existing architecture.
